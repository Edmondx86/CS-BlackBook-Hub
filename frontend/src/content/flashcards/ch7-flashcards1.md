# <span style="color: rgb(var(--brand));">无线链路与网络特征</span>

### 到这里为止，我们讲的链路都是“有线”的：网线、光纤，信号老老实实待在导体或玻璃里。可一旦换成无线，规则就全变了——信号在空气里四处乱窜，谁都可能听到，谁也都可能干扰谁。这一张卡我们先不急着讲 802.11，而是先搞清楚：无线链路到底“难”在哪里。

# <span style="color: rgb(var(--brand-dark));">7.2 无线链路与网络特征</span>

## <span style="color: rgb(var(--brand-dark));">无线链路的三大敌人</span>

### 和有线链路相比，无线信号要面对三个绕不开的物理现象：

* 路径损耗（path loss）：信号强度随传播距离迅速衰减。距离一远，收到的信号就弱得可怜。
* 干扰（interference）：同一频段上的其他信号会混进来——微波炉、蓝牙耳机、隔壁的 WiFi，都是“噪音源”。
* 多径衰落（multipath fading）：信号经墙壁、家具反射后，会以略微不同的时延到达接收端，几个副本叠加起来可能互相抵消，让信号忽强忽弱。

### 这三样加起来，结果就是：无线链路的误码率远高于有线链路。也正因如此，无线链路才愿花额外算力去做差错纠正，而有线链路出错直接丢弃就完事了。

## <span style="color: rgb(var(--brand-dark));">SNR 与 BER：一对此消彼长的冤家</span>

### 衡量无线链路质量有两个关键指标：

* SNR（信噪比）：信号功率与噪声功率的比值。SNR 越大，信号越“清晰”。
* BER（误码率）：比特传错的概率。BER 越低越好。

### 它们的关系是：**SNR 越高，BER 越低**。但这不是免费的午餐——想提高 SNR，就得加大发射功率（费电、伤身体）或者离基站更近（不现实）。所以无线协议必须在“功率”和“可靠性”之间做权衡。

### 更有意思的是，SNR 还决定了“一次能塞多少比特”：信噪比高的时候，可以用更复杂的调制方式，一个符号承载更多比特（速率上去了）；信噪比一低，就只能退回到保守的调制方式，速率跟着掉下来。这就是为什么你在信号弱的地方，WiFi 网速会明显变慢——它自动降速保命了。

## <span style="color: rgb(var(--brand-dark));">隐藏终端问题</span>

### 无线里还有个有线网络不会遇到的怪现象。假设 A 和 C 都能和 B 通信，但 A 和 C 相距太远、互相听不见。于是：

* A 检测信道，发现“没人说话”，就开始向 B 发送；
* 与此同时 C 也检测信道，同样觉得“没人说话”，也开始向 B 发送；
* 结果两个信号在 B 处撞车，B 一个都收不清。

### 这就是**隐藏终端问题（hidden terminal problem）**：**冲突发生在接收方，而不是发送方**。发送方因为听不到对方，永远无法靠“先听后说”避免碰撞。这也是为什么 WiFi 不能用有线那套 CSMA/CD（边发边听），而必须另想办法——下一张卡的 CSMA/CA 和 RTS/CTS 就是为此而生。

## <span style="color: rgb(var(--brand-dark));">CDMA：让所有人同时说话</span>

### 既然共享信道这么麻烦，有没有办法让大家干脆<strong>同时、同频</strong>发送还不互相干扰？有，这就是 CDMA（码分多址）。

### 它的思路是给每个发送方分配一个独特的编码（chipping code），发送时用这个编码去“扩频”，接收方再用同样的编码做内积运算，就能把属于自己的那路信号解出来，其他路信号因为编码正交而互相抵消。就像在一个嘈杂的房间里，几对人用不同的语言交谈——虽然声音混在一起，但每对人只听自己那门语言，照样能聊。

### CDMA 抗干扰能力强、保密性好，是 3G 时代的核心技术之一。

## 所以，无线链路的难点可以总结成一句话：**信号会衰减、会被干扰、会互相听不见**。理解了 SNR/BER 的权衡和隐藏终端问题，你就能明白为什么无线协议要设计得比有线复杂那么多——它不是想复杂，而是不得不复杂。
