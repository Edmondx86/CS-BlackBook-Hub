# <span style="color: rgb(var(--brand));">蜂窝网络：4G 与 5G</span>

### WiFi 解决的是“一小片区域里的无线接入”，覆盖范围通常只有几十米。可你走出家门、开车上高速、坐高铁，手机依然能刷视频打电话——撑起这张广域无线网的，就是蜂窝网络（cellular network）。它把整个国家的覆盖切成一个个“蜂窝”，再通过一套复杂的核心网把手机接进因特网。

# <span style="color: rgb(var(--brand-dark));">7.4 蜂窝网络</span>

## <span style="color: rgb(var(--brand-dark));">为什么要“蜂窝”</span>

### 无线信号衰减很快，一个基站覆盖不了太远。但如果只是简单地加大功率、拉大覆盖，会带来两个问题：频谱资源有限（同一频段不能到处重复使用）和用户容量受限（一个基站带不动太多人）。

### 蜂窝（cell） 的思想就是频率复用：把地理区域切成许多小格子，每个格子一个基站，相隔足够远的格子可以重复使用同一频段，因为距离够远、干扰可忽略。这样既扩大了覆盖，又成倍提升了系统容量。蜂窝越小，容量越大——这就是为什么城市里基站密密麻麻。

## <span style="color: rgb(var(--brand-dark));">4G LTE 的组成</span>

### 以 4G LTE 为例，整个体系可以分成两大块：无线接入网和核心网。

### 无线接入网部分：

* UE（User Equipment）：用户设备，也就是你的手机，里面插着 SIM 卡。
* eNodeB（ evolved Node B）：基站，负责和手机之间的无线通信，管理无线资源、调度上下行。
* `E-UTRAN`：由众多 eNodeB 组成的无线接入网整体。

### 核心网部分（EPC, Evolved Packet Core）主要由这几个角色构成：

* **MME（Mobility Management Entity）**：移动性管理实体，负责鉴权、跟踪手机位置、管理承载。它不碰用户数据，是纯控制平面的角色。
* S-GW（Serving Gateway）：服务网关，是用户数据进出核心网的本地锚点——手机在基站之间移动时，数据流的锚点尽量不变，避免连接中断。
* P-GW（PDN Gateway）：分组数据网网关，是核心网连接外部因特网的出口，负责给手机分配 IP 地址、做策略与计费。

### 一条数据的路径大致是：**手机 → eNodeB → S-GW → P-GW → 因特网**。可以把它理解成“无线版的接入网 + 一个专门管理移动性的运营商内网”。

### 这里还有一个关键设计：控制平面与用户平面分离。MME 只管信令（谁在哪、能不能连），S-GW/P-GW 只管搬数据。这和第五章 SDN 的思路如出一辙——只不过 SDN 用在有线网络，蜂窝网用在移动网络。

## <span style="color: rgb(var(--brand-dark));">5G 带来了什么</span>

### 5G 并不是简单地“把 4G 变快”，它在三个方面都有明显跃升：

* 更高的速率：峰值速率可达数 Gbps，靠的是更宽的频段（包括毫米波）和更高效的调制编码。
* 更低的时延：目标把端到端时延压到毫秒级，这对自动驾驶、工业控制、远程医疗这类场景是关键。
* 更大的连接密度：每平方公里能接入的设备数量提升一到两个数量级，为物联网（IoT）铺路。

### 在架构上，5G 把 4G 的网元进一步**服务化、虚拟化**：核心网功能拆成可独立部署的微服务（基于 NFV/SDN 思想），无线接入网也拆成 CU（集中单元）/DU（分布单元），以便灵活部署在不同场景。**5G 的很多理念，其实就是把 SDN 那一套“可编程、软硬解耦”搬进了运营商网络**。

## 所以，蜂窝网络的核心思想是“用频率复用把覆盖切小、把容量做大”，再用一套层次分明的核心网（MME 管控制、S/P-GW 管数据）把移动设备接入因特网。从 4G 到 5G，变的是速率和架构形态，不变的是“接入网 + 核心网 + 移动性管理”这三件套。
